# Invex.Extensions.Hosting

Small, dependency-light utilities for
[`Microsoft.Extensions.Hosting`](https://learn.microsoft.com/dotnet/core/extensions/generic-host) that remove
the boilerplate around shared-instance registrations, exit codes on shutdown and fixed-rate background work.

## Start here

- [Introduction](docs/introduction.md): what the library is for, when to use it, and its design principles.
- [Getting Started](docs/getting-started.md): install the package and run a first worker.
- [Multi-Interface Registration](docs/multi-interface-registration.md): one instance behind several service types.
- [Cycle Background Service](docs/cycle-background-service.md): drift-free periodic work.
- [API Reference](api/index.md): every public type and member.
